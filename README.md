# ที่ดินตรง ขอนแก่น

- หน้าเว็บ: GitHub Pages · ฐานข้อมูลและล็อกอิน: Firebase (โปรเจกต์ thidintrong-kk)
- 4 ภาษา: ไทย · ລາວ · English · 中文
- ตั้งค่าในไฟล์ `config.js` · คำแปลอยู่ใน `lang/`
- ขอบเขตอำเภอ: OpenGISData-Thailand
